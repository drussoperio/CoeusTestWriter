Test Generator

Load a JSON question bank, choose how many multiple-choice and true/false questions to pull from each category, then click Generate Test. The engine randomizes question order, shuffles answer choices, and balances the answer-key distribution. Export the finished test as DOCX, PDF, TXT, or JSON.

Input

Drag & drop file or click to browse

Generate Test

⚠️ Exact distribution can occasionally force repeated answers.
Controls how many times the same answer letter can appear consecutively in the MC section. 1 = strict alternation (no two adjacent answers can be the same letter). Higher values allow that many identical letters in a row before the engine forces a change. A very tight answer distribution combined with a low value may trigger a feasibility warning.
Controls how many consecutive True or False answers are allowed in the T/F section. 1 = strict alternation. 5 (default) allows up to five of the same answer in a row. Unchecking with a heavily skewed T/F ratio may trigger a feasibility warning.
