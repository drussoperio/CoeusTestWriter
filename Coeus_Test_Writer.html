Design a Test

Load a JSON question bank, choose how many questions to pull from each category, then click Construct Test. The engine randomizes question order, shuffles answer choices, and balances the answer-key distribution. Export the finished test in your chosen format.

▸ Load an existing .json bank file via drag-and-drop or the file picker.

▸ Set MCQ, T/F, and Matching counts per category, or use Smart Selection to distribute a target total evenly across categories. You can also select all available questions.

▸ Difficulty Ratio lets you control the Easy/Medium/Hard mix. If there are not enough questions, unset questions will be picked.

▸ Exclude Already-Used Questions prevents repeats across test versions — upload a previous test's JSON.

▸ The Generation Report tab shows a full breakdown including difficulty shortfalls.

▸ Export as TXT, DOCX, or JSON.

Write Questions

                    
Write questions from scratch and export them in multiple formats. Your questions are saved to your browser automatically.

▸ Export as JSON, CSV, TXT, or GIFT.

                        
Plain-Text Formatting Rules (Paste Text)

                        
▸ Number each question (1. , 2. , …). A question is only recognized if it has a number, period, and space before the question itself. Numbers can repeat and don't need to be in order.

                        
▸ Multiple choice: label choices with letters a.–e.. A choice is only recognized if it has a letter, period, and space before it. MCQ only accepts four to five choices. Prefix the correct choice with = or *. An error appears if no choice is marked correct.

                        
▸ True/False: put =True or =False on the line below the question.

                        
▸ Matching: consecutive premise/answer pairs (premise line, then =Answer line) are grouped into one matching question automatically.

Why Coeus Was Built

        
As a course team leader, I needed to collect and organize exam questions from multiple faculty members — balancing question counts per topic and per contributor. Existing tools weren't enough, so I turned to AI to build what I envisioned. ChatGPT got it started, but Claude brought the full vision to life.


        
What is Coeus?

        
Coeus is a browser-based exam question manager and test generator built for educators. It runs entirely client-side — no installation, no account, no internet required after load.


        
Built With

        
Vanilla JavaScript, Tailwind CSS, docx.js, Prism.js
